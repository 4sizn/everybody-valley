# 긴고랑 데이터와 화면 검증 (2026-09-08)

사용자 요청으로 기존 추정 구간 복원 후 그늘·시설·토지소유 경계를 연결했다.

- 중심선: 기존 trace.mts의 Terrarium 추정 경로. 실측 물길·보행로로 확정하지 않는다.
- 그늘: 기존 scripts/shade 파이프라인. 2019년 촬영 수관, 대표일 2026-08-01, 10~18시 9개 값. 정오 0.871, 18시 0.970. 추정 중심선 ±25m의 수관 아래 포함 비율이다.
- 지도: 사용자 요청에 따라 수관 면은 숨기고 개방지 그림자만 출력한다. 따라서 카드의 전체 그늘 비율과 지도에서 보이는 그림자 면적은 정의가 다르다.
- 시설: 전국공중화장실정보표준데이터(15012892) 긴고랑어린이공원 화장실, 전국주차장정보표준데이터(15012896) 구의2동 주택가공동 주차장. 제공 좌표 그대로, 현장 미확인. 시딩 재실행용 facilities-manual.csv에 출처를 기록했다. 계곡의 모든 시설을 전수 확인한 것은 아니다.
- 토지: 기존 서버 키로 브이월드 WFS dt_d160을 선택된 계곡 주변에서 실시간 조회한다. 파일·DB에 경계를 저장하지 않는다. 응답에서 소유자 관련 속성은 버리고 소유구분·검증된 기하만 전달한다. 1,000피처 한도 도달 시 일부 조회라고 알린다. 소유구분은 출입 허가/금지를 뜻하지 않는다.
- 토지 코드 근거: 국토교통부 2018 국가공간정보 표준화 연구용역 2권, 지적 모델 소유구분코드 표. https://www.codil.or.kr/filebank/original/RK/OTKCRK190212/OTKCRK190212.pdf
- 실제 조회: 폴리곤 203개(개인 67, 단체 10, 국공유 49, 미확인 77). 일부 조회 아님. 최신 소유권과 일치하는지는 장부 확인 필요.

그늘 재산출:

```sh
PYTHONPATH=scripts scripts/shade/.venv/bin/python -m shade build --segments data/valleys/gingorang.geojson --out data/shade
```

이번 로컬 검증은 다른 작업 서버와 충돌하지 않도록 API 8788, Expo 8082로 실행했다. 앱 시작 시 EXPO_PUBLIC_API_BASE=http://localhost:8788을 사용했다. 일반 기본 API 포트는 8787이다.
