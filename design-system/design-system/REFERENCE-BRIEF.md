# 모두밸리 디자인 시스템 — 레퍼런스 적용 기준

현재 상태: **카카오맵 실기기 녹화와 디자인 시스템 초안 작성 완료**. 아래는 촬영 전 기존 모두밸리 요구사항에서 정리한 설계 기준이다. 실제 관찰과 적용 결정은 [DESIGN-SYSTEM.md](DESIGN-SYSTEM.md)를 참고한다.

## 지켜야 할 제품 구조

- 선정 전: 주간 인기·안내 → 조건/검색 → 계곡 미리보기 → 명시적 선택.
- 선정 후: 큰 지도 → 그늘·시설·강우·제보 등 현장 작업. 선택 해제는 이전 탐색 맥락으로 복귀.
- 검색 결과의 대상을 보존한다. 계곡은 A04, 공영주차장·화장실은 A04를 거치지 않고 B10 시설 지도로 이동한다.
- 위험 단계와 정보 근거는 별개다. 자료 없음은 안전을 뜻하지 않는다.
- 현장 중요도: 위험 안내 → 현재 선택한 계곡/구간 → 지도 위 탐색 → 보조 정보·길찾기.

## 참고할 것과 별도로 설계할 것

| 영역 | 카카오맵 영상에서 확인할 내용 | 모두밸리에서 결정할 내용 |
| --- | --- | --- |
| 검색 | 진입/취소, 키보드, 결과 정보의 순서 | 계곡/시설 두 결과 유형과 다른 목적지 |
| 선택 | 핀·목록·상세가 같은 장소를 표현하는 방식 | 계곡·구간·시설의 선택 관계 |
| 시트 | 단계 이동, 손잡이, 닫기, 내부 스크롤 | 지도 확보, 경보·선택 구간 가림 방지 |
| 도구 | 지도 조작과 콘텐츠 탐색의 그룹 구분 | 그늘을 쉽게 찾고 시간 조작을 유지하는 배치 |
| 정보 위계 | 제목·유형·거리·보조 행동의 대비 | 출처·관측 시각·불확실성의 가독성 |
| 시각 규칙 | 면/경계/간격/아이콘/활성 상태 | 기존 녹색 팔레트를 바탕으로 한 고유 토큰 |
| 움직임 | 선택·확장·복귀의 연속성 | 움직임 감소 대안과 상태 보존 |

카카오맵의 브랜드 색·로고·전용 아이콘을 모두밸리 자산으로 복제하지 않는다. 지도 앱의 정보 구조와 상호작용 원리를 참고한다.

## 구성할 컴포넌트

1. 검색 필드: 기본/입력/지우기/취소/결과 없음.
2. 결과 행: 계곡형/시설형, 장소 이름·유형·다음 행동.
3. 계곡 카드: 순위/안내/비교/미리보기.
4. 지도 선택 헤더: 계곡·구간, 뒤로와 선택 해제의 구별.
5. 바텀시트: 접힘/중간/전체, 명시적 펼치기·접기, 내부 스크롤.
6. 지도 도구: 기본/활성/비활성, 아이콘과 행동 이름.
7. 시설 핀·요약: 유형 아이콘, 선택 표시, 정확한 목적지.
8. 시간 선택: 10~18시, 현재 선택·예측 시각·날짜.
9. 상태 배지: 위험 단계, 관측/추정/특보, 자료 없음/지연/실패.
10. 보조 행동: 길찾기·공유·좌표 복사와 주요 현장 작업의 우선순위.

## 모바일 접근성 설계값

기존 프로젝트 기준을 이어간다: 주요 터치 목표 48×48, 본문 16, 보조 14, 360/390px에서 줄바꿈·가림 방지, 색 외 이름/기호, 드래그 대체 버튼. 이는 모두밸리 목업의 설계값이며 카카오맵 측정값이나 실기기 접근성 검증 결과가 아니다.

## 근거 표기 방식

각 결정에 `영상 ID / 시각 / 관찰한 동작 / 모두밸리 적용 / 확인이 필요한 부분`을 기록한다. 실제로 측정하지 않은 크기·글꼴·애니메이션 시간을 카카오맵의 원본 토큰처럼 쓰지 않는다. 촬영이 완료된 뒤에만 관찰을 채우고 시스템을 확정한다.
