## 수정한 문제

- 고정된 full 시트 높이로 인한 상단 가림: 상단 실측 높이를 topInset으로 공급.
- 대피 상황의 일반 길찾기 우선순위: 대피 안내를 주요 행동으로 승격하고 모달에도 위험 요약 유지.
- 긴 이름 시나리오의 장소 혼동: 선택한 실제 fixture 이름 뒤에 긴 구간명만 추가.
- 보조 텍스트 대비: light text-muted 값을 조정하고 canvas/surface 조합 검사.
- form 안에서 원치 않는 submit: 비제출 컴포넌트에 type=button 지정.
- 사진 재사용 계약: 새 첨부에 원본 File과 미리보기 URL을 함께 제공. 업로드 어댑터가 사용할 수 있음.

## 범위

이 결과는 웹 UI 원본과 모바일 디자인 조합에 대한 검수다. 22쌍 대비 검사는 모든 배경·상태의 접근성 인증이 아니다. 기본 터치·가독성·비색상 상태 표현·가림·버튼 대안을 고려했으며 실기기 VoiceOver/TalkBack, OS 키보드, 200% 시스템 글자 확대는 검사하지 않았다. 브라우저의 폰트 대체와 플랫폼 렌더링은 소비 앱에서 확인해야 한다.

지도는 기존 설계 SVG 도식이다. 강우·시설·순위·제보는 시연 데이터다. 실제 지도 SDK, API, 위치 권한, 사진 EXIF 처리, 외부 길찾기, 데이터 저장은 연결하지 않았다. 라이브러리는 React 웹 구현이며 네이티브 플랫폼에는 토큰과 상태 계약을 이식한다.

검수한 조합에 남아 있는 P0/P1/P2 UI 문제 없음. 전체 실제 서비스 출시 완료를 뜻하지 않는다.
