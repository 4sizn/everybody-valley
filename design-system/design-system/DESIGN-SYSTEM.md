# 모두밸리 디자인 시스템 v0.1

카카오맵 iOS 실기기 녹화(2026-09-16)를 관찰하고 기존 모두밸리 목업 요구에 맞춰 정리한 디자인 기준이다. 관찰 대상은 지도, 검색 결과, 장소 요약/상세, 지도 설정, 정렬 옵션이다. 카카오맵의 내부 토큰·애니메이션 구현을 추출한 문서가 아니다.

## 1. 디자인 골자

**선정 전에는 비교, 선정 후에는 지도를 중심으로 설계한다.** 큰 지도 위에 선택한 대상과 필요한 행동만 남긴다. 정보가 많아지면 같은 대상의 시트를 확장하고, 접으면 지도와 선택 상태가 이어진다.

- 중립적인 흰 면과 약한 경계로 정보를 정리한다. 모든 카드를 강조 색으로 채우지 않는다.
- 초록은 선택·주요 행동에, 위험 색은 경보에 사용한다. 선택 상태와 위험 상태는 서로 다른 의미다.
- 장소의 이름이 가장 먼저 읽히고, 유형·구간·근거·시각이 뒤따른다.
- 지도 도구와 콘텐츠 행동을 분리한다. 기본 현장 화면의 핵심 행동은 그늘·구간 확인이다.
- 선택 대상이 계곡인지 시설인지 헤더·핀·시트·길찾기 목적지 전체에서 일치해야 한다.

## 2. 영상 근거 → 적용

아래 시각은 **검토용 편집본**의 구간 시작점이다. 구간 안에는 동작 전후 정지 시간이 포함된다. 해당 구간의 정확한 첫 변화 프레임을 뜻하지 않는다.

| 근거 | 실제 관찰 | 모두밸리 결정 |
| --- | --- | --- |
| 01 · 00:00 | 검색창·키보드·제안 목록에서 계곡 선택 후 지도와 요약 시트로 이동 | 결과 행은 이름·유형·다음 행동으로 구성. 계곡은 A04 미리보기, 시설은 B10으로 분기 |
| 02 · 00:00 | 중간 시트를 위로 드래그하면 전체 상세가 펼쳐짐 | B01/B03을 같은 선택 상태의 시트 단계로 다루고, 드래그 대체 펼치기 버튼 제공 |
| 02 · 00:10 | 상세 내부를 스크롤하면 간결한 제목과 탭이 상단에 남고 하단 행동이 유지됨 | 전체 정보에서 제목·현재 구간·접기와 주요 행동을 유지. 본문만 스크롤 |
| 02 · 00:22 | 접기 버튼으로 중간 지도 시트에 복귀. 아래 드래그로 제목·행동만 남음 | 접힘/중간/전체 3단계. 선택 해제와 시트 접기를 다른 행동으로 설계 |
| 02 · 00:41 | 최소 시트 상태에서 지도를 이동해도 선택한 장소 이름이 유지됨 | 지도 패닝이 선택 계곡·구간·시설을 바꾸지 않음 |
| 03 · 00:00 | 지도 설정은 배경을 어둡게 하는 하단 패널. 지도 유형과 추가 레이어가 분리됨 | 기본 지도와 그늘/토지 오버레이 설정을 구분. B02/B09의 주 오버레이는 하나만 활성화 |
| 03 · 00:14 | 지형도 선택 시 타일·아이콘·이름의 색이 변함 | 모두밸리는 색에 더해 체크와 `켜짐` 문구를 추가 |
| 03 · 00:28 | 패널 밖 탭으로 닫고 지도와 장소 선택을 유지 | 외부 탭과 명시적 `닫기`를 모두 제공. 설정 변경이 선택 대상에 영향 주지 않음 |
| 04 · 00:14 | 주차장 결과 선택 후 상단 제목·시트 제목·P 핀이 주차장을 가리킴 | A03→B10. 부모 계곡을 보조 정보로 유지하며 계곡 미리보기로 우회하지 않음 |
| 05 · 00:00 | 기존 검색어 뒤에 `주차장`을 입력하면 제안이 바뀌고 제출 시 결과 지도·목록이 나타남 | 자동 검색 제안과 확정 결과를 구분. 키보드가 뜨면 지도 도구보다 입력/결과 우선 |
| 05 · 00:24 | 정렬 칩을 누르면 현재 정렬에 체크가 있는 작은 선택 시트가 열림 | 필터는 단순 on/off 칩, 단일 선택 옵션은 체크 목록. 선택 개수·초기화 제공 |

시설 상세의 뒤로가기에서는 검색어가 선택한 시설명으로 바뀌고 최근 목록이 보이기도 했다. 이 구간은 검토용 클립에서 제외했다. **모두밸리는 원래 검색어·필터·스크롤을 복원**하는 기존 요구를 유지한다. 레퍼런스의 모든 동작을 그대로 채택하지 않는다.

## 5. 인터랙션 재현 명세

| 동작 | 전후 상태 | 유지할 맥락 | 제안 전환 |
| --- | --- | --- | --- |
| 계곡 선택 확정 | A04 → B01 접힘 | 계곡 ID·구간 ID·탐색 복귀 지점 | 지도 이동 300ms 출발점; 선택 구간이 시트 밖에 들어온 뒤 정지 |
| 시설 결과 선택 | A03 → B10 중간 | 시설 ID·부모 계곡·원 검색어 | 키보드 해제 → 선택 핀 → 요약 시트. 다른 장소로 제목이 바뀌지 않음 |
| 시트 드래그 | 접힘 ↔ 중간 ↔ 전체 | 선택 대상·레이어·시각 | 손가락을 따라 이동, 놓으면 가까운 단계로 정착. 속도 임계값은 추후 조정 |
| 시트 버튼 | 같은 단계 전환 | 위와 동일 | 220ms 출발점, 빠른 재입력 시 현재 위치에서 반전 |
| 내부 스크롤 | 전체 시트의 내용 이동 | 제목·접기·행동 고정 | 본문이 맨 위가 되기 전 아래 드래그를 접기로 오인하지 않음 |
| 오버레이 선택 | 기본 ↔ 그늘/토지 | 계곡·구간·카메라 | 활성 체크 갱신 → 레이어 표시. 선택 시각은 다시 켤 때 복원 |
| 선택 해제 | B → 이전 A 화면 | 검색어·필터·스크롤 | 선택 상태만 해제. 제보 작성 중이면 입력 보존 처리를 우선 |
| 움직임 감소 | 같은 상태 변화 | 모든 정보 | 즉시 전환 또는 짧은 불투명도 전환. 확대 이동·튕김 생략 |

120ms(눌림), 220ms(시트/패널), 300ms(지도)는 **모두밸리 시연용 초기값**이다. 녹화 원본은 10~15fps라 카카오맵의 정확한 easing·spring·지연시간을 역산하지 않았다. 드래그 로그의 durationMs는 입력 실행 시간이며 앱 애니메이션 시간이 아니다.

지도 카메라의 목표 영역은 `화면 - 상단 헤더/경보 - 시트 - 안전 여백`으로 계산한다. 지도 중심을 단순히 화면 중심에 두지 않는다. 시트 전체 모드에서는 지도를 가릴 수 있지만 접기 경로와 위험 상태를 유지한다.

## 6. 적용 순서와 범위

1. A03/B10: 결과 유형·시설 목적지 계약부터 적용.
2. B01/B03: 지도와 시트의 세 단계·같은 선택 유지·드래그 대안 적용.
3. B02/B09: 레이어 선택·범례·켜짐 표시·시간 조작 구성.
4. A01/A02/A04: 카드 비교 정보와 선정 CTA 위계 정리.
5. B04~B08: 상태·입력·오류 컴포넌트 재사용. 강우 수치나 안전 기준은 이번 레퍼런스로 결정하지 않음.

이번 산출물은 **디자인 시스템 초안, 편집 가능한 컴포넌트 보드, 인터랙션 시연, 실제 레퍼런스 영상**이다. 기존 15개 화면 전체를 이 스타일로 교체하거나 실제 앱을 구현한 상태가 아니다. 모바일 접근성은 목업 설계 수준에서만 다룬다. Android·다크 모드·스크린리더·실제 글자 확대 동작을 검증했다고 주장하지 않는다.
