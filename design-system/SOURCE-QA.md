## 필수 시각 검수

**글자**: 시스템 폰트 스택, 장소명 22/30, 행 제목 16/24, 보조 14/20을 적용했다. 작은 캡션은 13px이며 경보·대피는 14/20을 유지한다. 긴 이름은 줄바꿈한다. 카카오맵 내부 폰트를 추출했다고 주장하지 않는다.

**여백과 배치**: 좌우 16px, 검색 높이 48/radius 12, 시트 radius 20/손잡이 36×4. 버튼·지도 도구는 보이는 면 40px과 터치 48px을 분리했다. 조건 칩은 보이는 면 34px, 터치 44px이다. 접힌 시트의 지도 면적과 오른쪽 행동 그룹을 병치 확인했다.

**색**: 실기기 캡처에서 읽은 파랑 #206DEF, 흰 표면, 중립 회색을 적용했다. 보조 글자와 작은 파랑 글자는 대비를 보정했다. 다크는 카카오맵 실측이 아닌 모두밸리의 확장이다.

**자산**: 실제 캡처는 비교 문서에만 사용한다. 제품 지도는 기존 SVG 도식의 색을 보정했다. Lucide 아이콘을 유지했으며 카카오맵 전용 아이콘·사진·OS 크롬은 복제 범위에서 제외했다.

**문구**: 모두밸리의 계곡·시설 선택 계약을 유지한다. 카카오맵 평점·거리·광고를 가짜 데이터로 이식하지 않았다. 자료 없음과 대피 안내, 시설의 부모 계곡 맥락을 유지했다.

## 동작과 모바일 검수

- 360×844 / 393×852에서 실제 브라우저로 조작했다.
- 시설 검색 → 공영주차장 지도 → 선정 해제 후 ‘백운’ 검색 복원을 확인했다.
- 계곡 결과 → 미리보기 → 선정 → 시트 3단계를 확인했다.
- 제보 필수 오류, 이탈 확인, ‘계속 쓰기’ 후 본문 보존을 확인했다. 모달 너비 393px, 가로 넘침 없음.
- 다크 360px, 긴 이름, 대피, 전체 시트: 경보 하단 156px, 시트 상단 168px. 지도 도구는 숨김, 하단 행동은 ‘대피 안내 확인’이다.
- 비교 문서 360px에서 scrollWidth=360, 원본 크롭 8개 로드 정상.
- 브라우저 오류 기록 없음. 빌드와 대비·검색·필터·제보 모델 검사 통과.

## 허용한 차이와 남은 범위

90%는 사용자 목표이며 측정된 달성률이 아니다. 픽셀 복제를 주장하지 않는다. 지도 형상·서비스 콘텐츠·OS 영역이 다르므로 전체 화면 유사도 점수는 산출하지 않았다. 위험 배너와 시트 확장 버튼, 터치 영역은 모두밸리의 안전·접근성 기준으로 유지했다.

이번에는 기존 실기기 촬영 증거를 재사용했다. 추가 촬영, 실기기 다크, 보조기술, 200% 시스템 글자 확대는 검증하지 않았다. 정의한 컴포넌트 적용 범위에서 남은 P0/P1/P2는 없다.
