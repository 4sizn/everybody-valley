2026-09-16 실기기 녹화에서 추출한 캡처를 다시 관찰했다. 이번 수정에서 기기를 다시 연결하거나 추가 녹화하지 않았다. 현재 프로젝트에 보관된 원본1178×2556을393×852로 환산했다. 기기 화면 전체가 아닌 컴포넌트 형태·치수·위계를 적용 대상으로 삼았다.

색은 캡처에서 표본을 읽었으며 내부 카카오맵 토큰을 추출한 것이 아니다. 폰트는 플랫폼 시스템 스택이며 전용 폰트·브랜드 아이콘을 복제하지 않았다. 다크는 같은 의미 체계의 모두밸리 확장이다.

## 비교 방법

문서의 `#reference`에서8개 핵심 표면의 원본 크롭과 실제 공통 컴포넌트를 비교한다. `comparison-kakaomap-1.1.png`은 백운계곡 선정/접힌 시트 상태의393px 전체 비교이며, `comparison-components-1.1.png`은 헤더와 시트에 집중한다. `comparison-home-1.1.png`은 모두밸리의 수정 전후다.

90%는 사용자가 제시한 근접 목표다. 범용 점수나 픽셀 유사도로90%를 달성했다고 표기하지 않는다. 지도 형상·서비스 콘텐츠·OS 상태바·안전 경보 유무가 달라 전체 화면 픽셀 유사도는 의미가 없다. 카카오맵에 없는 강우 경보·그늘 시간·제보 기능은 모두밸리 계약을 유지했다.

캡처의 지도·사진은 참고 문서에서만 사용한다. 실제 UI의 지도는 기존 도식이며 카카오맵 지도 이미지를 서비스 배경으로 사용하지 않는다.
