# 변경 기록

## 1.1.0 · 2026-09-16

- 카카오맵 실기기 캡처에 맞춰 흰색·중립 회색·파랑으로 시각 방향 변경.
- 녹색 카드 바탕과 목록 외곽선 제거, 행 구분선과 작은 중립 아이콘 바탕 적용.
- 버튼은40px 보이는 면/48px 터치, 칩은34px 면/44px 터치로 분리.
- 지도 검색형 헤더48px, 원형 도구, 접힌 시트158px,22px 장소명.
- 8개 주요 컴포넌트의 레퍼런스 크롭과 라이브 비교 문서 추가.
- 작은 파랑 텍스트는 대비 보정용 accent-ink 역할로 분리.
- 다크·오류·검색 목적지 상태를 유지하고 모바일 배치 재검수.


## 1.0.0 · 2026-09-16

- Excalidraw와 정적 SVG 중심의 골격에서 실제 React UI 원본으로 전환.
- JSON에서 light/dark CSS를 생성하는 단일 토큰 체계.
- 24개 UI 컴포넌트와 IconProvider, TypeScript 선언, ESM/CSS 배포 파일.
- 검색·선정·시설 목적지·시트·제보 입력의 실제 조합.
- disabled/loading/error/empty/focus/selected 및 테마 상태.
- 위험 배너 높이와 긴 이름에 따른 시트 가림 보정.
- 기기 내 사진 미리보기와 URL 정리. 실제 업로드는 연결하지 않음.
- 의미별 텍스트 대비와 핵심 선택/검증 모델의 실행 가능한 검사.
