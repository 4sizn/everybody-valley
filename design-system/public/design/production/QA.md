# UI Library 1.1 · 모바일 시각 검수

2026-09-16. 이번 버전은 카카오맵 실기기 캡처와 비교해 색·여백·밀도를 재구성했다.1.0 검수 이력은 프로젝트의 design-system/revisions/에 보존했다.

- 393×852 수정 전후 홈 비교: 큰 녹색 면 제거, 평평한 목록으로 첫 화면 정보량 증가.
- 393×852 계곡 선정/접힌 시트: 카카오맵 원본과 병치하고 검색형 헤더·장소명·원형 도구·pill행동·시트 여백 확인.
- 360×844 시설 지도: 페이지너비360,scrollWidth360. 헤더48,접힌 시트158,지도 도구48×48,주요 행동48 높이. 공영주차장 대상 유지.
- 선정 해제 후 백운 검색어 복원. 계곡 결과는 미리보기→선정,시설 결과는 해당 지도.
- 전체 시트 뒤에 가려진 지도 도구를 display:none으로 제거. 시트 안 제보 행동 사용.
- 일반 제보 모달은 모바일 하단 시트.393 너비에서 넘침 없음. 빈 등록→aria-invalid=true,내용 입력→이탈 확인→계속 쓰기에서 입력 보존.
- 다크360/긴 이름/대피: 전체 시트가 경보 아래 위치하고 대피 행동을 유지.
- reference비교 문서는360px 가로 페이지 넘침 없이 원본8개 이미지 로드.
- light/dark22개 핵심 텍스트 대비 검사 통과.작은 파랑 글자는 별도accent-ink로 보정.
- 빌드,검색/필터/제보모델 검사 통과.브라우저 errors 기록 없음.

## 범위

이 검수는 브라우저에서의 모바일 UI와 디자인시스템이다. 이번에는 기존 실기기 녹화/캡처를 재사용했으며 새 기기 촬영은 하지 않았다. 카카오맵 내부 토큰 추출·90% 수치 달성·다크 실기기 관찰·네이티브 접근성 인증·실제 지도/서버 연결을 주장하지 않는다.44/48px조작영역과 비색상 상태 이름,위험 위계,시트 버튼 대안을 유지한다.
