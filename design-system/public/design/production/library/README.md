# 모두밸리 UI Library 1.1 — 디자인과 구현 계약

## 기준의 변화

이 버전의 기준은 실제 DOM으로 렌더링하는 컴포넌트다. Excalidraw나 화면 SVG가 구현 원본이 아니다. 문서의 표본과 모바일 적용 예시는 같은 React 컴포넌트와 토큰을 가져온다. 24개 UI 컴포넌트, IconProvider, 두 가지 서비스 패턴(JourneyPreview / ReportComposer)을 제공한다.

1.1은 사용자의 카카오맵 컴포넌트 유사도 요청에 따라 실기기 캡처에서 색·치수·밀도를 다시 맞췄다. 흰 표면, 검정 본문, 파랑 행동, 평평한 목록, 원형 지도 도구, 작은 pill 행동을 적용했다. `#reference`에서 원본 크롭과 실제 컴포넌트를 비교한다. 내부 디자인 토큰을 추출한 것이 아니며 90%는 목표이지 측정 달성률이 아니다.

## 파일 구조

- `tokens.json`: 모든 테마의 의미별 색과 타입/간격/둥글기/모션/레이어 원본.
- `library/index.js`, `index.css`, `index.d.ts`: React ESM 컴포넌트, CSS, 타입 선언.
- `source/`: 정리된 JSX/CSS/JSON 원본과 서비스 패턴·시연 데이터.
- `icons/`: Lucide 0.468.0 SVG 34개와 라이선스. 도형을 글리프로 대체하지 않는다.
- `preview.html`: 360/390 실제 브라우저 너비로 조작하는 모바일 UI.
- `check-results.json`: 반복 실행 가능한 대비·도메인 검사의 실제 결과.
- `QA.md`: 수동 브라우저 검수와 적용 범위.

## 적용 예

```jsx
import {Button, IconProvider} from './library/index.js';
import './library/index.css';

<IconProvider baseUrl="/assets/moduvalley/icons">
  <div className="mv-system" data-theme="light">
    <Button icon="navigation" onClick={openSelectedFacility}>
      시설 길찾기
    </Button>
  </div>
</IconProvider>
```

React 18.3.1을 기준으로 빌드했다. React/React DOM은 소비 앱이 공급한다. SVG 디렉터리를 공개 자산 경로에 복사하고 IconProvider로 그 URL을 지정한다. CSS는 호스트 앱의 디자인과 충돌을 줄이도록 `mv-` 접두어를 사용하며 `.mv-system`이 타이포·컴포넌트 범위다. CSS 의미 토큰은 `--mv-` 접두어다. 시연 페이지의 `studio.css`는 라이브러리 배포 CSS와 별도다.

`tokens.json`을 수정한 다음 생성기를 실행한다. 생성된 tokens.css를 직접 수정하지 않는다. 원래 프로젝트에서 `npm run build:design`, `npm run check:design`을 실행한다. 전달 ZIP의 scripts 및 package.json으로도 같은 검사를 실행할 수 있다.

## 토큰 계층과 변경 규칙

1. 기반 값: spacing 4/8/12/16/20/24/32/40/48, control/card/sheet radius, 역할별 type.
2. 의미 값: text, text-secondary, text-muted, accent, on-accent, danger, caution, info, surface, canvas, border, focus 등.
3. 컴포넌트 규칙: 입력48, 버튼 터치48/보이는 면40, 아이콘 터치48, 목록 내부10~16, 도형24/20, 버튼 간격8. 사용처마다 비슷한 값을 새로 만들지 않는다.

색은 light/dark 대응 역할로 바뀐다. 위험 색과 선택 색은 독립적이다. 공개 API의 역할명 변경·삭제는 주요 버전, 하위 호환 변형 추가는 부 버전, 배치/상태 오류 수정은 패치로 관리한다. 새 컴포넌트는 기존 구성으로 표현할 수 없는 사용자 과업이 있을 때 추가한다.

## 공개 컴포넌트와 상태

| 계열 | 컴포넌트 | 지원 상태 |
|---|---|---|
| 행동 | Button, IconButton, MapTool | 기본·hover·pressed·focus-visible·선택·disabled·loading |
| 입력 | Field, SearchField | 기본·입력·focus·hint·error·required·disabled·readonly·지우기 |
| 선택 | Chip, Segmented, Switch | 미선택·선택·키보드 포커스·비활성 |
| 피드백 | Badge, Alert | 주의·경보·대피·관측·추정·없음·지연·실패·완료 |
| 콘텐츠 | Card, ValleyCard, FacilityRow, Metric, Notice | 긴 이름·근거·미확인·선택 장소 |
| 탐색 | Tabs, MapSheet | 선택 탭·방향키·3단계 시트·내부 스크롤·손잡이 드래그·버튼 대안 |
| 복구 | EmptyState, Skeleton | 0건·자료 없음·로딩·복구 행동 |
| 시간 | TimePicker | 10~18시·range·이전/다음·끝값 제한·비활성 |
| 중단/완료 | Dialog, Toast | 열림·닫힘·Escape·배경 클릭·취소 확인·완료 피드백 |
| 사진 | PhotoInput | 0~3장·파일 선택·기기 내 미리보기·삭제·객체 URL 정리 |
| 자산 | Icon | 16/20/24, 임의 검토 크기. 실제 SVG 마스크와 currentColor |

브라우저 네이티브 포커스 동작을 사용한다. Dialog는 showModal/close와 HTML dialog의 포커스 관리를 따른다. 제목·설명 ID를 연결하고 위험 확인에서는 계속 쓰기를 기본 행동으로 둔다. 모든 컴포넌트가 반드시 모든 상태를 가지는 것은 아니다. 예를 들어 loading은 Button/데이터 표시에 적용되고 Card 자체의 상태가 아니다.

## 서비스 상태 계약

### 선정 전

검색·주간 안내·관심 계곡·필터·안전 진입의 순서. 필터는 값이 `true`인 조건만 충족한다. null을 무료/야영 가능 등으로 승격하지 않는다. 검색은 입력 즉시 결과를 바꾸며 활성 필터의 영향 없이 통합 검색한다.

계곡 결과 → 조건 미리보기 → 구간 선택 → 명시적 선정. 시설 결과 → 해당 시설 지도. 공영주차장·입구 화장실을 계곡 미리보기로 보내지 않는다.

### 선정 후

같은 selected entity가 헤더·핀·시트·길찾기 목적지를 결정한다. 시설은 parent valley ID를 유지한다. 실제로 해당 계곡에 속하는 시설만 보여준다. 계곡으로 돌아가면 부모 계곡이 선택된다. 선정 해제는 이전 검색어를 복원한다.

시트는 peek/half/full 제어형 상태다. 손잡이 이동24px 이상이면 인접 단계로 이동하며, 모든 단계에 버튼 대안을 둔다. 긴 이름과 위험 배너의 실측 높이를 관찰해 `topInset`을 계산하므로 full 시트가 경보를 가리지 않는다. 전체 시트에서는 지도 지점이 가려질 수 있으며 ‘지도 크게’로 복귀한다.

### 위험

위험 단계·근거·자료 상태를 분리한다. 자료 없음은 안전이 아니다. 대피 상태에서는 일반 탐색 대신 대피 안내를 하단 주요 행동으로 올린다. 제보 모달에도 경보/대피 요약을 유지한다. 실제 임계값과 공식 지침은 데이터 어댑터가 공급한다. 이 패키지의 강우 상태는 디자인 검토용 시나리오다.

### 제보

유형 → 본문 → 사진 → 공개 위치 → 등록. 내용은 공백을 제외해 필수 검사하고 500자 제한을 예시로 제공한다. 미완성 이탈은 계속 쓰기/내용 폐기 확인. 처리 중 중복 제출을 막고 실패 시 본문·사진·지정을 보존한다. 성공 시 해당 제보를 같은 계곡의 목록에 추가한다. 시연에서는 컴포넌트 메모리만 바뀌고 서버로 전송하지 않는다.

## 실제 제품 연결 지점

| 어댑터 | 소비 앱이 공급할 것 | UI가 보장할 것 |
|---|---|---|
| 지도 | 실제 SDK, 좌표, 카메라, 지형/레이어 | 대상 이름·도구·시트·선정 상태 유지 |
| 강우 | 단계·근거·관측 시각·자료 상태 | 단계별 위계, 회색 unknown, 오류 복구 |
| 시설 | 시설 ID/유형/부모 계곡/목적지 좌표 | 시설 제목·시트·목적지 일치 |
| 길찾기 | 검증된 목적지와 OS 외부앱 실행 | 명시적 시설 길찾기 행동 |
| 사진·제보 | 업로드/EXIF 제거/저장/권한/실시간 갱신 | 공개 안내, 입력 보존, 처리 상태·재시도 |
| 네이티브 | 플랫폼 폰트·안전영역·키보드·접근성 API | 플랫폼 공통 토큰과 행동 계약 |

배경 지도는 이전 설계에서 가져온 도식이며 토지·그늘은 시연 이미지다. GIS 결과를 계산하지 않는다. 가짜 실시간 값이나 실제 검증된 시설 정보를 제공한다고 주장하지 않는다.

## 품질 기준

기본 본문16/24, 보조14/20, 보조 캡션12/18. 중요한 상태 설명을 캡션으로 축소하지 않는다. 입력은16 이상이며 주요 행동48, 필터 칩44의 조작 영역을 제공한다. 360에서 글자를 줄이는 대신 문구 줄바꿈과 내부 스크롤을 쓴다. reduced-motion 설정에서 애니메이션을 즉시 전환한다.

프로덕션 디자인 시스템의 구현 기준과 실제 제품의 출시 검증은 다르다. 이 패키지는 사용 가능한 웹 UI 원본과 검수된 참조 조합이다. iOS/Android 네이티브 실행, 실제 지도 SDK, 서버·보안·실기기 보조기술 검증은 제품에 연결한 뒤 수행한다. 이를 이번 디자인 검수의 완료 주장에 포함하지 않는다.

PhotoInput이 새로 만든 항목은 `name`, `url`, 원본 `file: File`을 포함한다. 소비 앱은 `file`을 업로드 어댑터에 전달하고 처리 결과를 관리한다. 외부에서 이미 저장된 사진은 `file` 없이 URL로 제공할 수 있다.
