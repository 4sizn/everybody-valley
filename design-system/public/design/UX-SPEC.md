# 모두밸리 UX 목업 설계서

이 문서는 `screens.json`과 `scripts/generate.py`의 15개 화면 정의를 기준으로 작성했다. 목적은 **계곡 선정 전의 발견·비교**와 **선정 후의 지도 중심 이용**을 분리하고, 검토할 사용자 흐름과 출시 전 요구사항을 명확히 하는 것이다.

## 산출물의 범위

사용자가 확정한 현재 작업 범위는 서비스 흐름·배치·정보 중요도와 **모바일 접근성의 목업 설계 고려까지**다. [모바일 접근성 반영 기준](MOBILE-ACCESSIBILITY.md)을 적용하며, 아래에 기록한 실제 제품 검증 항목은 이번 목업의 완료 조건이 아니다.

현재 확인한 산출물은 편집 가능한 Excalidraw 화면 요소, 화면별 내보내기 정의, 클릭 영역과 화면 연결 메타데이터다. 순위·시설 거리·경보·좌표·그늘은 시연 데이터이며 지도는 실제 지리 정보가 아닌 도식이다. 모든 화면에 시연 표기를 유지한다.

검토 뷰어의 화면 전환과 동작 피드백은 설계를 확인하기 위한 시연이다. 화면에 버튼이 있거나 동작 이름이 정의돼 있다는 사실은 실제 서비스 기능의 완성을 뜻하지 않는다. 서버, 공공 API, 실시간 구독, 실제 좌표, 데이터 수치, 경보 기준은 검증하지 않았다. 일반 안전 안내의 참고 자료는 아래 공식 페이지에서 확인했으며, 이는 앱이나 현장 상태의 안전성 인증이 아니다. 웹·iOS·안드로이드 앱 구현 완료나 배포 준비 완료를 주장하지 않는다.

## 핵심 UX 결정

1. **후보 열람과 계곡 선정을 구분한다.** 홈 카드와 계곡 검색 결과는 미리보기로 연결한다. 시설 검색 결과는 A04를 거치지 않고 해당 시설을 강조한 B10 지도로 직접 연결한다. `이 계곡 선택 · 큰 지도 열기`를 누를 때 선정 후 모드로 전환한다.
2. **선정 후 기본 화면은 큰 지도다.** 구간 요약은 접힌 시트로 제공하고, 그늘·시설·토지는 지도 위에서 확인한다. 필요한 정보만 펼친다.
3. **선택 해제는 이전 탐색으로 돌아가는 명시적 행동이다.** 하위 화면의 뒤로와 구별하고, 선택 전에 보던 검색·필터·스크롤을 복원한다.
4. **전역 내비와 현장 도구의 모양을 구별한다.** 선정 전은 `홈 / 계곡 찾기 / 설정` 3개 탭이다. 선정 후는 `구간 정보 / 현장 제보 / 길찾기` 버튼형 작업바다. 소식은 홈 주간 안내로, 제보는 현장 모드로 통합했다.
5. **알 수 없는 상태를 안전으로 표시하지 않는다.** 자료 없음·갱신 지연·연결 실패를 나누고, 위험 단계와 정보 근거의 종류를 별도로 보여준다.

## 단계 진입·복귀 규칙

### 일반 진입

`A01 홈 또는 A02 탐색 → A04 미리보기 → 선택 버튼 → B01 현장 지도`

선정 전 계곡 카드 탭만으로 선정 후 상태가 되지 않는다. 시설 결과 탭은 시설 위치 확인을 명시적으로 요청하는 별도 진입이다. A04에서 후보를 확인하고 나갈 수 있다. 선택 시 계곡 ID와 구간 ID를 함께 확정한다. 초기 구간이 자동 선택된다면 CTA 주변과 현장 헤더에 동일한 구간을 보여준다.

### 검색·시설 진입

`A01/A02 → A03 검색 → 계곡 결과 → A04 미리보기 → 선택 → B01
시설 결과 → A04 없이 B10 시설 지도`

- 검색 중에는 조건 필터를 잠시 적용하지 않으며 그 사실을 결과 위에 알린다.
- 시설 결과에는 `계곡명 · 시설명 · 유형`과 `시설 지도 보기` 행동을 표시한다. 결과를 누르면 부모 계곡을 지도 맥락으로 설정하고 B10에서 그 시설을 강조한다. 지도 핀·시설 카드·길찾기는 동일한 시설 ID·명칭·유형을 유지한다.
- B10에서 선택 해제하면 A03의 검색어와 결과로 돌아간다. 계곡 지도 보기는 같은 계곡의 B01로 이동한다.
- 선택을 완료하면 현장 화면의 검색 입력은 비운다. 해제 복귀에 쓸 이전 검색어는 별도 탐색 스냅샷에 남긴다.
- 검색 지우기·닫기는 검색을 열기 전의 탐색 조건으로 돌아간다. 홈에서 연 검색을 항상 A02로 보내는 것은 완전한 이전 상태 복원과 다르므로 실제 구현에서 분리해야 한다.

### 뒤로·선택 해제

- B03/B04/B05의 지도 복귀는 계곡 선택을 유지한다.
- B06 뒤로는 B05로, B08의 위치 확정·취소는 작성 중 B07로 돌아간다.
- `선택 해제`는 마지막 선정 전 페이지·검색·필터·스크롤을 복원한다. 미리보기만 반복해서 다시 열리는 복귀는 피한다.
- 정상적인 선택 해제에 매번 확인창을 띄우지 않는다. 작성 중인 제보가 있을 때만 `임시 저장 / 폐기 / 계속 쓰기`를 제공한다.
- 설정·안전 안내는 현재 선택 계곡·지도·그늘 시각을 바꾸지 않는다. 열기 전 화면으로 돌아간다.
- 같은 계곡의 다른 구간 선택은 선정 후 모드를 유지한다. 다른 계곡을 찾으려면 선택 해제 후 탐색한다.

### 직접 링크·새로고침

계곡 ID·구간 ID·시트 단계·그늘 시각을 복원 가능한 상태로 정의한다. 직접 링크로 처음 들어와 이전 탐색 스냅샷이 없다면 선택 해제 시 A02로 이동한다. 공유 URL에 사용자 GPS나 제보 초안을 포함하지 않는다. 실제 직렬화·복원·유효하지 않은 ID 처리는 구현과 별도 검수가 필요하다.

## 지도와 시트의 관계

시트는 **접힘 / 절반 / 전체**의 세 단계다. 규칙 보드의 약 16% / 48% / 88%는 설계 목표이며 기기 실측 결과가 아니다. 상단 상태 영역, 하단 작업바, 안전 여백을 포함하는 기준을 구현 전에 고정해야 한다. 현재 B01은 작업바와 요약을 함께 보여주므로 접힌 전체 영역이 16%보다 클 수 있다.

| 단계 | 목적 | 지도와의 관계 |
| --- | --- | --- |
| 접힘 | 선택 구간 요약과 현장 행동 | 기본 진입; 지도가 화면의 약 65~75%를 차지하도록 설계 |
| 절반 | 시설·구간 조건 빠르게 확인 | B03처럼 지도를 남기고 선택 핀을 보이게 함 |
| 전체 | 긴 정보·목록 읽기 | `지도 크게 보기`를 제공하고 대피 배너는 가리지 않음 |

- 시트를 올릴 때 선택 구간이나 시설이 가려지지 않도록 지도 카메라에 가려진 영역을 반영한다.
- 그늘·토지 탐색을 시작하면 시트를 접어 지도를 확보한다. 시설을 누르면 행과 핀을 함께 강조하고 가려짐을 해소한다.
- 시트 손잡이는 현재 작업의 높이를 조절한다. 제보 위치 선택 중 손잡이를 눌러 구간 정보 페이지로 이동해서는 안 된다.
- 그늘과 토지 경계는 주 오버레이 하나만 활성화한다. 시설 점 표시는 별도 보조 표시로 둘 수 있다. 오버레이를 바꿔도 선택 시각 등 설정은 보존한다.
- 기본 지도에는 선택 계곡·구간, 강우 상태, 현장 작업바의 우선순위를 유지한다. 긴 안내를 지도 중앙에 상시 쌓지 않는다.

## 제보·위치·개인정보

제보 유형은 불법 사유지·쓰레기·긴급 신고·계곡 새정보·미아찾기·물건찾기 6종이다. 사진은 최대 3장을 목표로 하며, 지도 위치 선택을 왕복해도 내용·유형·사진을 유지한다. 위치를 확정한 후 작성 폼에 선택 좌표 또는 위치 요약을 보여줘 등록 전에 확인할 수 있게 한다.

기기의 GPS 위치와 사용자가 지정한 공개 제보 지점을 구별한다. GPS는 기기 내 지도 조작에 이용하며 서버로 전송하지 않는 것이 제품 요구다. 제보에 붙이는 좌표는 사용자가 지도에서 명시적으로 지정하고 공개 범위를 안내받은 위치다. 외부 공공 API에는 사용자 GPS 대신 계곡 좌표를 사용하는 요구를 유지한다.

EXIF 제거는 화면 문구만으로 보장되지 않는다. 실제 업로드 경로에서 서버가 사진 메타데이터를 제거하는지 검증해야 한다. 제보 등록·사진 업로드·좌표 복사·119 전화·운영 신고는 각각 독립된 행동이며, 목업 시연을 실제 전송·긴급 신고로 표시하지 않는다.

## 모바일·큰 화면·테마

- **기준 원본:** 390×844 모바일 화면. 이는 편집용 원본 크기이며 지원 기기의 검증 결과가 아니다.
- **360~591px:** 유동 여백과 가로 스크롤 가능한 칩을 사용한다. 핵심 버튼·입력·좌표가 잘리지 않게 하고 하단 안전 여백과 키보드 표시를 고려한다.
- **592px 이상:** 선정 전 콘텐츠는 중앙 최대 560px 컬럼, 선정 후 지도는 넓은 배경과 중앙 최대 560px 시트로 확장한다. 지도에서 실제로 보이는 영역에 선택 지점을 맞춘다.
- **테마:** 라이트·다크·시스템 설정을 공통으로 적용한다. 다크 지도에는 별도 지형·물길·필지·그늘 팔레트를 사용하고 경보와 범례를 색만으로 구분하지 않는다. 현재 라이트 원본과 테마 설계 규칙을 실제 다크 화면 검증으로 간주하지 않는다.
- **모바일 접근성:** 기존 원본의 클릭 영역은 메타데이터 기준 최소 44px이며, 후속 목업은 [모바일 접근성 반영 기준](MOBILE-ACCESSIBILITY.md)의 48×48 터치 목표·글자·상태 구분·가림 방지·읽기 순서를 적용한다. 단순 축소로 모바일 대응을 대신하지 않는다. 실제 기기 보조기술 동작이나 표준 적합성 검증은 이번 작업의 완료 조건이 아니다.
- **움직임:** 지도 이동·목록 전환·시트 애니메이션은 상태 변경을 설명하는 정도로 사용한다. 제보 티커와 새 글 도착이 읽는 위치를 강제로 바꾸지 않게 한다.
