# 모바일 접근성 · 목업 반영 범위

사용자 요청에 따라 기존 서비스 흐름·배치 검수에 **모바일 접근성의 설계 고려까지만** 포함한다. 아래는 다음 목업 수정에 적용할 기준이며, 현재 화면이 모두 충족한다는 검증 결과는 아니다.

| 항목 | 목업 반영 기준 |
| --- | --- |
| 터치 영역 | 주요 버튼·닫기·시간 선택·필터는 48×48 논리 단위를 설계 목표로 둔다. 작은 아이콘도 누를 영역을 별도로 확보하고 인접 영역이 겹치지 않게 한다. |
| 글자 | 본문 16, 보조 정보 14를 기본 설계값으로 잡는다. 경보 상태·제보 좌표·주요 행동은 작은 각주에 넣지 않는다. 긴 이름과 글자 확대 시 줄바꿈할 공간을 둔다. |
| 상태 구분 | 강우 단계·선택된 구간·그늘·토지 범례는 색과 함께 이름·아이콘·선택 표시로 구별한다. 자료 없음과 안전을 구별한다. |
| 좁은 화면 | 360px·390px 폭에서 주요 행동·좌표·안전 안내가 잘리지 않는 배치를 그린다. 화면 전체를 축소해 맞추지 않고 여백·줄바꿈·배치를 조정한다. |
| 가림 방지 | 하단 안전 영역·키보드·시트 높이를 고려한다. 선택 구간과 지도 도구, 등록 버튼이 겹치지 않게 한다. 긴 내용은 스크롤할 수 있게 설계한다. |
| 조작 대안 | 시트 드래그에는 펼치기/접기 버튼, 시간 트랙에는 탭 선택, 지도 이동에는 전체 보기 등 명시적 대안을 둔다. |
| 이해·읽기 순서 | 아이콘의 행동 이름과 선택 상태, 제목→현재 상태→내용→주요 행동의 읽기 순서를 설계 주석으로 남긴다. 필수 항목과 오류는 해당 입력 가까이에 표시한다. |

숫자는 이 목업의 작업 기준이며 접근성 표준 적합성 인증을 뜻하지 않는다. 모바일 화면 낭독기 동작, 실제 글자 확대·터치 실측, 데스크톱 접근성, 실제 지도·API·서버 기능 검증은 이번 목업 완료 조건에 포함하지 않는다.
