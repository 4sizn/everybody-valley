## v1 이 되려면 남은 것

**OPS1 이 마지막 기능 항목이다.** 그 뒤 셋이 남는다 — 기능이 아니라 출시 작업이다.

| # | 무엇 | 왜 v1 안인가 |
| --- | --- | --- |
| 1 | **법적 문서** — 개인정보처리방침·이용약관 | 제보가 닉네임·비밀번호 해시·**IP** 를 저장한다. 문서 없이 공개 서비스로 못 낸다 |
| 2 | **배포 실행** — S1 (c) 대상 결정 후 서버·웹 올리기 | 지금 서버는 로컬만 돈다. 제보 사진도 로컬 디스크다 |
| 3 | **버전·태그** — `0.1.0 → 1.0.0`, `v1.0.0` 태그, `docs/PARITY.md`·`CLAUDE.md` 에 동결 표시 | 동결의 실체 |

**DS1(색 감축 106→75)은 v1 에 넣지 않는 쪽을 권고한다.** 검수는 받되 **적용(앱 전체 이관)은 v2**
로 미룬다 — 색 토큰을 전면 교체하면 모든 화면을 다시 검증해야 하고, 그 사이 v1 동결이 늦어진다.
DS1 의 실측 결함 중 **경보 배지 AA 미달(2.09~2.93:1)** 만은 v1 에 넣을 값이 있다 — 안전 앱에서
경보가 안 읽히는 것은 결함이라 별 항목으로 뽑아 v1 에 태우는 것을 제안한다.

## v2 로 넘기는 것

- **DS1 색 감축 적용** — 검수 승인 뒤 전면 이관.
- **계정·로그인** — 지금 제보는 닉네임+비밀번호, 관리자는 토큰(OPS1 임시). 계정이 들어오면
  **OPS1 의 10탭 제스처와 토큰을 제거한다.**
- **네이티브(android/ios)** — X1 자리표시자 넷(사진 선택·지도 피커·클립보드·레이아웃 플립) +
  네이티브 시각 검증. 빌드가 느려 미뤘다(사용자 2026-09-07).
- **경보 확장** — F3c 푸시(배포·네이티브 의존) · F3d 특보 신호(API 게이트웨이 미등록) ·
  F3s 격자 강수(보류).
- **막힌 기능** — N2 막차 역산(게이트웨이) · N4 위성 토글(VWorld 회신) · R5 수계 벡터(다운로드).
- **미뤄둔 것** — N3 119 좌표 카드(제보 좌표로 흡수) · L1 계절 확장·등고선 v2 · X5 경미한 겹침 ·
  문구 별건(`나무 많음` vs `나무 그늘 많음`).
