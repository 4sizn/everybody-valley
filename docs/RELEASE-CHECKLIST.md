# 공개 서비스 전 운영 설정

저장소 빌드/로컬 프로덕션 검증과 공개 서비스 출시는 구분한다.

- [ ] 서버·도메인·TLS와 운영 origin 지정.
- [ ] 실제 정부 API 키·호출 권한·데이터 이용 조건 확인 및 관측 갱신 확인.
- [ ] 운영자 명칭/연락처, 개인정보 처리 목적·보유기간·삭제/문의 경로, 이용약관 확정 및 앱에서 연결.
- [ ] 외부 지도/타일 제공자와 사진 저장 위치를 포함한 운영 처리 흐름 검토.
- [ ] ADMIN_TOKEN 발급, DB/사진 백업·복원, 접근 로그 보관/삭제 정책 설정.
- [ ] 실제 운영 기기·네트워크에서 지도, 제보, 이미지, 경보, 접근성 최종 확인.

## 현재 코드가 처리하는 정보

- 공개: 제보 본문·유형·닉네임·생성시각·재인코딩 사진·작성자가 명시한 지점.
- 비공개 서버 저장: 제보 비밀번호의 bcrypt 해시, 작성/신고 IP, 운영용 접속 로그.
- 기기: 테마 선택. 새 웹 운영자 토큰은 페이지 메모리에만 보관.
- 사진: 서버가 장변 1600px 이하 JPEG로 다시 만들고 EXIF를 제거. 원본은 저장하지 않음.
- GPS: 기기 위치 권한을 요청하거나 GPS 위치를 수집하지 않음.
- 보유: 원본 서버에는 제보/신고 기록의 자동 만료가 없다. 실제 운영 보유기간을 정한 후 삭제 절차를 적용해야 함.

이 문서는 출시 설정 목록이며, 확정된 개인정보처리방침/이용약관을 대신하지 않는다. 운영자 정보나 보유기간을 임의로 만들어 넣지 않았다.
