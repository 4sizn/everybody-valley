# 모두의계곡 — 제품 아이디어

spotts.kr/firework 분석에서 파생. 2026-09-01 정리.

## 전제: spotts와 다른 축

spotts는 **하루짜리 이벤트 지도**라 "어디서 볼까" 하나만 풀면 됩니다.
계곡은 **반복 방문 + 안전 + 시간대**가 축입니다. 실제 질문은 두 개예요.

> 지금 갈까? / 지금 나와야 하나?

그래서 지도만으로는 부족하고 **예측과 알림**이 제품의 중심이 됩니다.

## 1. 킬러 후보 3개

### 1-A. 상류 강우 경보 — 이 앱이 존재할 이유

계곡 사망사고는 대부분 국지성 호우로 상류에서 물이 밀려올 때 납니다.
방문자는 자기 머리 위가 맑으면 위험을 모릅니다.

```
한강홍수통제소 실시간 강우·수위 (10분 단위)
  + VWorld 표준유역 폴리곤으로 계곡↔상류 관측소 자동 매핑
  → "상류 10분 강우 22mm — 지금 물에서 나오세요" 푸시
```

- 기술 난이도 낮음, 사회적 가치 큼 → 지자체 제휴·언론 노출까지 이어짐
- 임계값은 보수적으로. 오경보가 몇 번 나는 게 미경보 한 번보다 낫습니다
- 경보 이력을 남겨 사후 검증(실제로 수위가 올랐나)을 하면 임계값을 조정할 수 있음

### 1-B. 시간대별 그늘 지도

계곡 방문의 실제 의사결정은 "오후 3시에 저 자리 그늘 지나?"입니다.
지도 앱에서 본 적 없는 뷰라 이거 하나로 기억됩니다.

```
DEM(수치표고) + 태양 고도(SunCalc) + 계곡 방향
  → 시간대별 그늘 폴리곤을 빌드 타임에 GeoJSON으로 생성
  → 시트에 시간 슬라이더, 지도에 그늘 영역 애니메이션
```

- 런타임 계산 아님. 계곡당 1시간 간격 12장을 미리 굽습니다
- V자 골짜기는 평지보다 그림자가 훨씬 빨리 져서 체감 효과가 큼
- `firework-areas` 폴리곤 레이어 구조를 시간축으로 바꾸면 그대로 재사용

### 1-C. 119 좌표 카드

계곡은 주소가 없습니다. 사고가 나면 위치 설명을 못 합니다.

- 국가지점번호 + 위경도 + 가장 가까운 진입로/도로명을 **한 화면에 크게**
- 통신 음영 대비: 마지막 위치와 주변 시설을 localStorage에 캐시해 오프라인에서도 표시
- 만드는 데 하루, 가치는 큼

## 2. 데이터 모델 — 점이 아니라 선

spotts의 Spot은 Point지만 계곡은 **LineString**입니다.
상류/중류/하류가 수심·혼잡·그늘이 전부 달라서 하나로 묶으면 정보가 뭉개집니다.

```
계곡 (LineString)
 └ 구간 segment ×3~5
     수심대      knee | waist | adult
     바닥재      gravel | rock | sand
     그늘 비율   0~1
     접근 거리   주차장→물가 m
     접근 경사   DEM에서 산출
     금지 여부   물놀이 금지 구역인가
```

카드 제목은 "백운계곡", 부제는 **"중류 · 무릎 · 그늘 많음 · 주차장 320m"**.

### 티어 컬럼은 데이터 생성 시점에 굽는다

spotts가 클러스터링 없이 2,700개 마커를 뿌리는 방법 그대로:

| 컬럼 | 의미 |
|---|---|
| `mapIconTier` | 0 = 유명 계곡, 1 = 지선, 2 = 소규모 소(沼)·명소 |
| `mapLabelTier` | 라벨 노출 줌 단계 |
| `mapImportance` | 심볼 정렬 우선순위 |

## 3. 페인포인트 직격 기능

| 기능 | 근거 |
|---|---|
| 주차 만차 제보 + 대안 주차장 거리순 | 계곡 방문 1번 스트레스. 따릉이 3단계 색 그대로 재사용 |
| 도보 접근 난이도 | 주차장→물가 거리·경사·계단. 아이·유모차·노약자 동반이 절반 |
| 막차 역산 알림 | "막차까지 47분, 지금 출발" — 대중교통 방문자 |
| 자릿세/평상 정보 | 청정계곡 정비 이후 "무료 개방 여부"가 실제 검색어 |
| 조건 필터 | 아이 동반 / 반려견 / 주차 무료 / 야영 / 그늘 많음 |
| 이동시간 등시선 탐색 | "서울에서 1시간 이내" — 계곡은 목적지보다 이동시간으로 고름 |
| 위성 토글 | 벡터 지도로는 수면 폭·갓길 주차 공간이 안 보임. VWorld 정사영상 |

## 4. 실시간 · 커뮤니티 (spotts 구조 그대로)

- **사진 제보 + EXIF 좌표·시각 자동 추출** → 타임스탬프 붙은 현장 피드. SSE 채널 그대로
- **물 맑기 3단계 제보** — 비 온 다음날 흙탕물인지가 핵심인데 어디에도 없는 정보
- **체크인 기반 혼잡도 자동 집계** — spotts 번들에 지오펜스·자동 체크인 코드가 이미 있음
- **별점 리뷰는 넣지 말 것.** 계곡은 컨디션 변동이 커서 작년 별점이 오늘과 무관합니다.
  대신 **최근 7일 제보만** 노출하고, 그 이상은 접어두기

---

## 5. 안 하는 게 나은 것

- **예약/결제** — 자릿세 논란에 휘말립니다. 정보 제공에만 서 있는 게 안전
- **전국 커버리지 먼저** — 수도권 30~50개만 구간 단위로 깊게.
  spotts도 여의도 하나에 시설 95개를 박았습니다
- **앱 설치 요구** — 웹으로 시작. 계곡은 검색 유입이 대부분
- **하천구역 무단점유 단정 표기** — 경계 레이어만 보여주고 판단은 사용자에게

## 6. 계절 문제

여름 3개월 서비스라는 게 구조적 약점입니다. 두 갈래:

1. **같은 지도 셸로 콘텐츠만 교체** — 가을 단풍, 겨울 얼음축제·눈꽃.
   spotts가 실제로 이 구조입니다(라우트별 시트 스냅 + 레이어 세트를 갈아끼움).
   `/valley`, `/autumn` 라우트를 나누면 코드상 거의 공짜
2. 여름에만 켜고 나머지는 정적 아카이브

1번을 권합니다.
