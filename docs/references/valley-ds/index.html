모두의계곡 디자인 시스템

설계 원칙

이 시스템이 다른 모바일 UI와 갈라지는 지점 다섯 가지. 계곡 서비스에서도 이 다섯은 유지하는 게 좋습니다.

  • 지도가 배경이 아니라 본문이다. 모든 UI는 지도 위에 떠 있고, 시트·GNB·검색바가 지도를 가리는 면적을 최소로 잡습니다.
  • 떠 있는 것은 전부 알약. radius-full이 전체 라운드 사용의 절반(95회)입니다. 카드만 12px, 시트만 상단 16px.
  • 테마는 토큰 한 겹으로만. 컴포넌트 CSS에 색 리터럴이 없고 --spot-color-* 30개만 교체하면 다크/라이트가 통째로 바뀝니다.
  • 8px 리듬, 4px 미세조정. gap 사용 상위 두 개가 sm(8px) 78회, xs(4px) 76회. 12px(smd)이 카드 내부 패딩의 기본값.
  • 모바일 단일 폭. 미디어 쿼리 브레이크포인트는 min-width:768px 하나뿐. 나머지는 hover·pointer·prefers-* 능력 질의입니다.

컬러

시맨틱 토큰 30개. 원본은 vanilla-extract 컨트랙트(vars.color.*)로 노출되고 런타임에는 --spot-color-* CSS 변수로 떨어집니다. primary 계열과 on* 계열은 두 테마가 같은 값을 씁니다.

토큰LightDark쓰임
토스 계열 뉴트럴입니다. #191f28 / #8b95a1 / #f2f4f6 / #f04452 / #15b76d는 토스 프로덕트 팔레트와 동일 계열이라, 한국 사용자에게 “익숙한 앱”처럼 읽히는 효과가 큽니다. 계곡 서비스에서도 뉴트럴은 그대로 두고 accent만 바꾸는 편을 권합니다.

타이포그래피

Pretendard Variable 한 벌 + 숫자·코드용 Geist Mono. 굵기는 400 / 500 / 600 세 단계만 쓰고 bold와 semibold가 둘 다 600입니다(700은 실질적으로 미사용).

행간 공식

11px부터 30px까지 1px 단위로 클래스가 다 뚫려 있고, 행간은 두 구간 규칙을 따릅니다.

line-height rule
lineHeight = fontSize <= 17 ? fontSize * 1.5 : fontSize + 9
// 11→16.5  12→18  15→22.5  17→25.5 │ 18→27  24→33  29→38  (30→40 만 예외)

실제로 쓰이는 단

12 / 400본문·설명 — 화면에서 가장 많이 쓰임(70회)
12 / 600배지 · 강조 라벨
15 / 600카드 제목 · 세그먼트 · 버튼 (37회)
16 / 400기본 본문 · 인풋
11 / 400캡션 · 보조 메타

본문 15px·제목 15px으로 크기 차이 대신 굵기(400↔600)와 색(foreground↔secondary)으로 위계를 만듭니다. 지도 위 좁은 시트에서 정보 밀도를 지키려는 선택이고, 계곡 카드에도 그대로 유효합니다.

계곡으로 이식

뉴트럴·간격·라운드·그림자는 그대로 두고 accent만 교체합니다. spotts의 파랑(#297cff)은 “도심 야간 이벤트”의 색이고, 계곡은 물·이끼 쪽 청록이 주제와 맞습니다.

accent 제안

토큰값흰 글자 대비쓰임
primary#0c8b804.2 : 1CTA·활성 상태. 15px/600 이상에서만
primaryStrong#076a626.5 : 112px 이하 소형 텍스트·아이콘
primaryHover#0a7d73—hover
link (dark)#2fbfb27.8 : 1 (다크 바탕)다크에서 링크·강조

참고로 원본 #297cff에 흰 글자는 3.9:1로 본문 텍스트 AA(4.5:1)에 못 미칩니다. 위 값은 그보다 낫게 잡았고, 작은 글자에는 primaryStrong을 쓰면 AA를 넘깁니다.
