## UI 차이를 의도적으로 적용한 곳

- 시연 순위/예시 시설·안전 수치는 실제 카탈로그로 교체했다. 추가 요청에 따라 홈은 주간 안내·광고 배너와 실제 최근 7일 관심 선택 순위, 계곡별 블로그로 재구성했다. 계곡 찾기는 검색·필터·전체 목록에 집중한다.
- 기존 전체 지도 중심 탐색을 선택한 계곡 중심으로 바꿨다. 지도 엔진은 그대로 사용한다.
- 기존 실시간 제보 티커는 선택 계곡의 제보 탭으로 옮겼다.
- 관리자 진입은 웹 설정에 명시했다. 권한은 숨겨진 제스처가 아니라 API 인증이 결정한다.
- 기본 지도 도구는 mockup2의 그늘·시설·토지·제보. 3D 등 기존 카메라 기능은 지도 조작 메뉴에서 제공한다.
- 데스크톱 탐색은 560px 읽기 폭, 지도는 전체 화면을 사용한다.

## 원본에 이미 남아 있던 범위

`modu-valley/docs/RELEASE_V1.md` 기준으로 네이티브 사진 선택·지도 피커·클립보드·시각 검증, 푸시, 막차 역산, 위성 토글, 수계 벡터 확대 등은 원본에서 다음 버전으로 미뤄져 있었다. 새 웹에 완성 기능인 것처럼 버튼/데이터를 만들지 않았다. iOS/Android 코드·의존성·타입/어댑터 테스트를 보존했지만, **이번 웹 UI가 네이티브에도 이식됐다고 주장하지 않는다.**

## 저장소 구조

- `design-system/src/design-system`: mockup2 UI Library 원천.
- `packages/ui`: 생성된 React UI1.1 배포물.
- `apps/valley-map/src/journey`: 새 웹 사용자 흐름.
- `apps/valley-map/src/app/index.web.tsx`: 새 웹 진입.
- `apps/valley-map/src/app/index.tsx`: 보존된 네이티브 진입.
- `packages/core`, `adapter-web`, `adapter-native`, `map-style`: 원본 기능/엔진.
- `server`: 원본 API + 선택적 정적 웹 호스팅.
- `data`: 기존 계곡/시설/그늘 및 원본 출처·검수 수준.
