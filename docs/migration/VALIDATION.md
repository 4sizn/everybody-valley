## 주변 시설 탭 — 중심선 기준·종류별 묶음 (2026-09-20)

- 시딩은 계곡 점 반경 1.5 km 원(`scripts/seed/facilities.mts`)이라 물가에서 1 km 넘는 식당까지 섞여 있었다(전체 376개 중 중심선 500 m 밖 168개, 1 km 밖 36개). 데이터는 그대로 두고 core `Valley.facilitiesAround()` 가 **중심선까지 거리** 300 m(주차장·진입로·역은 800 m)로 "주변"과 "가는 길에"를 가른다.
- 시설 탭 맨 위 요약 한 줄(`facilitySummary`): 종류별 개수, 주차장은 가장 가까운 거리, 화장실·주차장은 없어도 "없음", 끝에 "쓰레기는 되가져가기". 종류별 묶음(h4) 안은 가까운 순, 행 부제는 "물가에서 N m · 운영시간". 시트 부제 "주변 시설 N곳" 도 주변 개수로.
- OSM 실측(용추계곡 중심선 300 m, 2026-09-20): 공공시설 태그(waste_basket·recycling·drinking_water·playground·life_ring·toilets 등) 전부 **0건**, 정자 1·안내판 1·이름 없는 공원 1만. 쓰레기통·놀이터는 OSM 으로 못 채운다 — 수기·지자체 데이터만 길. 그래서 시설 유형 추가는 하지 않았다.

## 계곡 주변 산 이름 라벨 (2026-09-23)

- 사용자 요청 "계곡 주변의 산이름 정보도 맵에 표기 — 매봉산(678.8m)". 봉우리 라벨 레이어(`terrain-peak-label`, openmaptiles `mountain_peak`)는 이미 있었는데 계곡 화면에서 한 번도 보이지 않았다. 단독 MapLibre 페이지(같은 합성 스타일)로 재현: **3D 지형(`setTerrain`)을 켠 채 타일 최대 줌 14 를 넘으면 타일 심볼이 그려지지 않는다** — z13.9 → 2개, z14.1 → 0개, 지형을 끄면 z14.2 → 1개. 계곡 화면 기본 줌이 14.2(개요)·15.5(구간)라 항상 빈 것. 앱 안에서는 z12 에서도 비었는데 원인은 더 좁히지 못했다(맵 인스턴스에 접근할 통로가 없어 캡처만 가능).
- 해결: **자체 GeoJSON 봉우리 소스**(오버줌 18 부터라 문제 없음). `pnpm seed:peaks` 가 OSM `natural=peak`(이름 있는 것)을 중심선 3 km 안에서 받아 `data/peaks/<id>.geojson`(33곳·282개, 최소 3개) → `peaks-bundle.json` → core `Peak`/`ValleyDataset.peaks` → `MapContent.peaks` → map-style `PEAK_LAYER_SET`(`valley-peak-label`, 줌 10+, "▲ 이름 표고m", 표고 높은 순, 비인터랙티브). 구간 정보 탭에 **"주변 산"** 지표 추가 — 중심선에서 가까운 봉우리 3개(`nearbyPeaks`, 같은 이름 중복 노드는 가까운 것만).
- 타일 라벨은 그대로 둔다(z11~13.9 에서는 둘이 겹쳐 충돌 규칙이 하나만 남긴다). 표고는 OSM `ele` 그대로(예: 언니통봉 928, 석룡산 1147.4) — 사용자가 예로 든 "매봉산 678.8"과 같은 소수 한 자리도 있는 그대로 보인다.
